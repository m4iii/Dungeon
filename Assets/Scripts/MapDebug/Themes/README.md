# 地图主题

在 **Dungeon → 地图调试台** 选择「地图主题」，然后点击生成。当前默认配置为林间溪谷。
地图配置负责规模、布局、怪物、宝箱、普通事件和种子；主题负责陆地分布、河流、湖泊、阻挡山和主题事件。
点击「编辑主题规则与素材」修改主题，或复制资源并修改唯一标识和显示名称。补齐内置主题菜单只创建缺失资源。

## 山体与事件

每个主题用 **Wall Mountain** 选择一种阻挡山，整张地图保持一致：

- 密林腹地：林木山地。
- 林间溪谷、湖畔森林、开阔草原：裸岩山地。
- 冰封雪岭：山脚、山峰均覆雪的雪山。
- 沙漠主题：主题素材中的台地。

林间溪谷默认增加一个绿色山脚、峰顶积雪的事件格。**Peak Event Count** 控制数量，**Peak Event Id** 绑定事件内容（默认 `snow-peak`）。事件格可通行，不混入阻挡墙，也不替代原配置的怪物和宝箱。主题事件需要主路房间布局；接入正式游戏时需在事件目录配置对应 ID 的剧情、选项与奖励。

## 河流与湖泊

- 河流生成不分叉的连续路径，移除自相邻造成的假交汇，使用素材支持的直段和弯段，不拼造分叉。
- **River Target Length** 为期望河道长度，默认 12 格。比较多条无分叉候选路线，优先跨越地图内部，对连续贴边走向扣分。受空间和内容保护约束时可能短于目标。
- 河段端口统一对齐；上游使用泉源素材。末端接近边界且方向合适时，可穿过一格自动外围阻挡区朝外出水，不能沿外围绕行；没有合法出口时用原包末端素材收尾。
- **River Surfaces** 指定河流可以经过的低地底图。温带主题默认草地、疏林，林间溪谷还允许森林低地；沙漠为沙地，寒冷主题为雪原。雪林、岩地与冰面默认不允许，可按素材兼容性调整。
- 自动生成的内部阻挡区可预留为河谷，使用相邻合法低地作为河岸，保持阻挡属性，不把水叠在山素材上。手工山地、水域和内容格不覆盖。外围只允许末端朝外出水。
- 已有低地保留原底图。`surfaceTerrain` 保存绘制河道下方的底图；新预留的河谷与河口使用相邻河岸底图。
- 河流穿过可通行空地时生成浅滩，保留原来的通行关系；入口、宝箱、战斗、事件和手工指定地形不被覆盖。
- 内置湖泊为单格小湖，湖畔森林有三处。**Pond Width** 控制宽度（完整格宽为 2）；保持素材比例，最多显示原生像素大小，不跨格拉伸。
- 湖泊使用阻挡区域；空间不足可能扩展地图边缘。水域无法放置时明确报告错误。

陆地权重是分布倾向而非精确配额。森林以片区生成，外围转为疏林并穿插空地。
JSON 导出版本 6 保存主题名称、配置快照、生成地形以及河流覆盖前的 `surfaceTerrain`；修改主题后需重新生成预览。

## 城镇与特殊地点

主题的 **Locations / 城镇与特殊地点** 配置每种地点的名称、交互 ID、数量、陆地类型及六边形/方格素材。数量设为 0 可关闭，也可以增加条目接入新的整格地点素材。

- 林间溪谷、湖畔森林、开阔草原：村镇、城堡、农场各一处。
- 密林腹地：村镇、伐木营地各一处。
- 矿场提供素材和配置，默认数量为 0。
- 沙漠、雪地默认不放温带建筑，需配套素材后自行开启。

地点通过必放事件格参与主路房间生成，不覆盖已有内容或入口，不减少原配置必放数量；底层为可进入的陆地，河流和湖泊不能覆盖。地点过多时沿用生成器的容量校验。
点击地点可查看名称和交互 ID，导出包含地点 ID 与主题素材配置。当前实现的是地图生成与预览；具体交易、任务、生产及奖励需要在正式游戏事件目录中为对应 ID 配置。

## 地形连续性

开启主题的 **Continuous Regions** 后，陆地使用统一的平滑空间分布生成连续区域，而不是逐格随机混合。**Patch Size** 为片区尺度，内置主题现为 16；提高后区域变化更缓慢。地形权重用于区域分配，边界整理和指定地点会使最终比例有所偏移。

温带地形形成平原—疏林—密林的过渡，移除缺乏同类邻居的零碎地块。固定地形、城镇等指定地点保留自己的底图；山墙仍服从主路房间布局与统一山体配置，不因视觉整理改变可通行范围。湖泊继续使用单格原尺寸素材。

## 视觉修整

河道寻路保持整体下游方向，并对长度远大于首尾距离的绕行扣分，避免为凑长度画出回头弯。素材预览不再重复绘制内缩深色网格；选中、邻格和布局调试高亮仍保留。
沙漠主题启用 **Arid Rocks**，将岩地显示为砂岩色；复制主题时该设置随配置保留，原始图片不修改。

## 当前水系设置

全部主题已关闭河流与支流生成（Rivers = 0）。湖泊和地点配置保留；补齐内置主题也不会重新开启河流。

沙漠阻挡山体改为 **低矮砂岩山地（Sandstone）**，使用低矮山地轮廓与砂岩色，不再用高耸石柱台地铺墙。两种沙漠主题均已应用；仅改变外观，不改变不可通行属性。

## 生成素材试用

森林、草原与沙漠主题现通过 **Wall Hex Texture** 引用 GeneratedTerrain/Candidates 的两张生成素材。**Clip Wall To Hex** 在预览渲染时裁掉地块外部柔光；不修改原始 PNG。清空覆盖纹理即可回到 **Wall Mountain** 外观。雪地和方格模式仍使用原有素材；通行规则、地点和湖泊数量不变，河流仍关闭。
