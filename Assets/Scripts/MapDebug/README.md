# 地图调试台

Unity 菜单 **Dungeon → 地图调试台**，无需 Play Mode，不修改场景。

## 查看地图

1. 选择 Presets/DefaultMapDebug.asset，点击“生成”。
2. “新种子生成”按时间取新种子；输入存档 InitialSeed 与 RegionIndex（首区域为 0）可复现相同配置的初始地图。
3. 滚轮缩放，中键/右键拖动，左键选格。“居中”适配视口。
4. “显示布局”：主路金色边框，房间入口粉色边框，文字带房间编号；选中格白色，邻位浅蓝。详情显示距入口最短步数。
5. “显示地形素材”使用 Arts 样包；关闭则显示色块。浅水亮青色可进入，高山与深水不可进入。浅水使用平静海面提亮，不是样包自带浅水分类。
6. 导出 JSON 保存当前成功结果和配置快照；改参数不会自动更新旧预览。

左侧编辑 SO，可撤销；“保存”写入配置，“另存配置”保留方案。SO 保存规则，不保存每局地图。

## 默认配置

六边形，空间按格数自动分配，入口 (12,2)，最低 60 格，主路长 12，1 个出口，房间 5～9 格，目标空地比例 0.45。额外保证 5 个奖励、8 场战斗、1 个休息点，其余从池抽取。debug-wolf 仅为预览用敌人 ID。

## 参数

| 参数 | 说明 |
|---|---|
| Grid | Hex 六边形轴向坐标，Square 四邻接方格 |
| 自动生成空间 | 不再配置 Width / Height；根据格数、内容容量、主路长度及固定坐标分配空间。房间空间不足时最多扩展两次，仍保留资源保护上限 |
| Irregular Shape | 不规则模式；关闭后填满完整网格 |
| Road Room Layout | 默认开启主路＋分支房间；关闭可对照旧连通生长 |
| Cell Count | 房间模式为最低通行数量，必放内容、空地比例和固定地点连线可能扩大规模；旧模式为精确数量。不计阻挡格 |
| Main Road Length | 自动出口距入口的步数，范围内必须有足够的该距离候选。没有任何出口时仍生成同长度主路 |
| Exit Count | 自动出口数量 1～4；关闭 Place Exit 时以固定出口为准 |
| Min / Max Room Size | 包含房间入口。受空间限制可小于抽取目标，但不低于最小值；最后一间可因剩余格数更小 |
| Empty Ratio | 未固定位置的目标空地比例；必放内容优先 |
| Required Content | 额外必放数量，不抵扣固定地点同类内容；影响地图规模，无法满足时报错 |
| Branch Chance | 低值优先沿主路扩展，高值允许更多房间接房间；旧模式仍为延伸偏好 |
| Compactness | 仅对旧生长模式有效；房间模式优先紧凑扩展 |
| Place Exit | 房间模式先确定出口；旧生长模式选择最远格；完整网格选择右上角。固定出口需关闭此项 |
| Pool | 房间模式忽略 Empty、Exit、Blocked；空地由 Empty Ratio 控制。Boss 池只在需首领且无固定/必放首领时补一名。战斗需敌人 ID，交互需 Content ID |
| Fixed Cells | 坐标不可重复或覆盖入口。Override Terrain 固定地形；高山、深水不能承载事件 |
| Require Boss For Exit | 必须有首领配置；房间模式可以从首领池补一名 |
| Generate Terrain | 补阻挡圈、封闭内洞并分配地形片区 |
| Water Chance | 每片阻挡区域抽成深水的概率，其余为高山；非精确面积比例 |
| Terrain Patch Size | 越大倾向越大片同类地形，不保证每片格数 |
| Shallow Shores | 深水旁已有通行格转浅水，不增加通行格；入口与显式地形不变 |
| Plains / Woodland / Forest Weight | 草原、疏林、森林片区权重 |
| Terrain Visuals | SO 可覆盖六边形/方格贴图，默认 Arts 样包；按 256×384 布局绘制 |

## 生成流程

绕开固定阻挡，先连接入口、出口和固定地点，再从主路/已有房间旁扩展分支。新房间只通过入口格接触已有区域，主体之间留阻挡间隔。每次扩展都连入已有区域，最后再检查连通性；不删除固定障碍、不重抽种子。空间不足时自动扩展内部生成区域；仍无法找到布局时显示已放格数、目标和候选房间大小。用户种子与必放内容不变。

首领优先深处；奖励优先尽头、分支及低邻接数格；战斗优先房间入口、奖励邻位与关键路径；商店/休息优先较近处。这些是位置偏好，不保证每个奖励有守卫或每间房只一个奖励。

自动锁门避开主路及通往首领/商店的保护路径；固定锁门阻断关键目标时拒绝生成。其他支路的钥匙获取顺序不保证。

随后为通行格邻位补实际阻挡格，并填满封闭内洞。圈外才是地图外部。浅水只替换已有通行格，不改变连通性。不需要岸线拼接。

## 分层和存档

SO 转成 Core 定义，窗口与 GameRun 共用 RunSeeds.GenerateRegion；Core 不引用 Unity，地图随机流与战斗/掉落分离。

相同配置（含 Map ID）、种子、区域序号与算法版本才能复现。输入 InitialSeed，不是 RandomState 或派生地图种子。探索进度从整局存档恢复；文件 I/O 由应用层负责。

生成算法版本 **3**，旧生成版本存档拒绝恢复。调试 JSON 版本 **4**，包含地形、通行性、mainRoad、roomId（从 0 开始，非房间 -1）、roomEntrance、depth（无布局 -1）及配置快照，不是整局存档。布局元数据由种子重建。

窗口关闭/重编译后需重新生成。调试器不执行战斗，也不验证敌人/交互 ID 的目录存在性。没有新增或运行测试。

生成版本 4：移除手动宽高。房间模式 Cell Count 仍为最低可通行格数；完整网格模式按 Cell Count 生成紧凑区域。外围阻挡圈另计。
